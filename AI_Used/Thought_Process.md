# Thought Process

The project began with our own ideation of the basic VPN architecture. We made the main design decisions ourselves, including using a userspace implementation and designing the packet header format.

We then used AI for the following:

1. ChatGPT Web was used to learn relevant concepts and explore ideas for the security portion of the project.
2. Once the ideation stage was complete, Codex was used to finalize the implementation plan.
3. Codex produced the project code and carried out the software testing.
4. We independently handled the Raspberry Pi 5 setup, environment configuration, command execution, deployment, and troubleshooting on the physical systems.
5. We also performed all benchmarking and collected the experimental measurements.
6. Codex created the report, and ChatGPT Work created the presentation. We reviewed both and made the final changes and edits.

This workflow allowed AI to handle much of the implementation and documentation work while we retained responsibility for the core design decisions and all hands-on experimental work.
